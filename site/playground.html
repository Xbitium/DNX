Watch a name become an address.

Type any name below. Everything on this page is computed in your browser by the same rule the protocol uses — the hashed fields are real SHA-256, truncated exactly as the implementation does it. Nothing here is a mock-up.

1 · Address explorer

A DNX address is four 64-bit fields. The top two are assigned by a registry, which is what makes routes aggregate. The bottom two are derived from the label, so anyone can name their own hosts without asking permission.

Change a single character of the host label and watch the bottom field change completely — that is the avalanche property of the hash. Change the domain and only the assigned field moves.

2 · Follow it through the network

This walks the address through the same four-router topology that is running live on two datacenters right now. Each hop reads exactly one field and nothing else.

How that address is framed for transmission. The payload is already sealed before the routing header is attached, which is why routers can forward what they cannot read.
